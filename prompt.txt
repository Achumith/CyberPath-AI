Build a full-stack cybersecurity project called **“CyberPath AI – AI-Powered Dynamic Cyber Attack Graph and Attack Path Prediction System.”**

The goal of this project is to create a cybersecurity platform that models an organization's IT infrastructure as a graph, automatically identifies possible attack paths, uses machine learning to estimate the risk of those paths, and uses an AI explanation layer to explain how an attacker could potentially move through the environment.

This is an educational and defensive cybersecurity project. It must operate entirely on synthetic/simulated infrastructure data and must not perform real-world exploitation, scanning, credential attacks, or unauthorized network activity.

---

# 1. CORE IDEA

Represent an organization's infrastructure as a graph.

Nodes can represent:

* Internet
* Routers
* Firewalls
* Web servers
* Application servers
* Databases
* Employee computers
* Admin computers
* User accounts
* Domain controllers
* Cloud resources
* Sensitive data repositories

Edges represent relationships such as:

* Network connectivity
* Can communicate with
* Can authenticate to
* Has access to
* Runs on
* Depends on
* Can potentially reach

Each asset contains security attributes.

Example:

Web Server:

* Asset type: Web Server
* OS: Linux
* Internet exposed: Yes
* Open service: HTTPS
* Vulnerabilities: simulated CVEs
* CVSS score: 8.5
* Privilege level: Low
* Asset criticality: Medium

Database:

* Asset type: Database
* Internet exposed: No
* Sensitive data: Yes
* Asset criticality: Critical
* Authentication required: Yes

The system should then calculate possible attack paths through the graph.

Example:

Internet
↓
Web Server
↓
Application Server
↓
Database
↓
Sensitive Data

The system should identify this as a potential high-risk attack path depending on the properties of the nodes and edges.

# 10. MACHINE LEARNING MODEL

Do NOT claim that the ML model magically discovers the attack graph.

The graph engine discovers candidate paths.

The ML model predicts the risk associated with each path.

Create a synthetic training dataset containing thousands of simulated attack paths.

Each row should contain:

* path length
* CVSS values
* vulnerability count
* high-severity vulnerability count
* internet exposure
* privilege escalation
* authentication requirement
* asset criticality
* sensitive-data access
* number of hops
* network exposure
* privilege level
* number of security controls

Target:

risk_score

or:

risk_class

Classes:

Low
Medium
High
Critical

Generate labels using a transparent rule-based scoring function initially.

For example:

Risk increases when:

* The path starts from the Internet.
* A high-severity vulnerability exists.
* Few privileges are required.
* The path reaches a critical asset.
* Sensitive data can be reached.
* Multiple vulnerabilities exist.
* Privilege escalation is possible.

Train models such as:

1. Logistic Regression
2. Random Forest
3. XGBoost

Compare them using:

* Accuracy
* Precision
* Recall
* F1 score
* ROC-AUC where appropriate

Do NOT rely only on accuracy.

Display the results in the application.
